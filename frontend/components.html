စည်းမျဉ်း ခြောက်ချက်

ဒီဇိုင်း ဆုံးဖြတ်ချက် တိုင်းက ဒီခြောက်ချက်ထဲက တစ်ခုကို ပြန်ညွှန်းနိုင်ရပါမယ်

1

ခ က မျက်နှာပြင်ပေါ်မှာ အကြီးဆုံး

ခရီးသည် ဆုံးဖြတ်တာက ကိန်းဂဏန်းတစ်ခုပါ။ ကိန်းဂဏန်းက စာလုံးထက် အမြဲ လွယ်ပါတယ်။

.fare — 48px / Arial Black
2

မြန်မာစာက အဓိက၊ အင်္ဂလိပ်က ဒုတိယ

အင်္ဂလိပ်စာက မြန်မာစာကို ဘယ်တော့မှ အစားမထိုးပါ။ ဒါပေမဲ့ မြန်မာစာ မဖတ်တတ်သူအတွက် တစ်ခုတည်းသော လမ်းညွှန်ဖြစ်လို့ 12px အောက် ဘယ်တော့မှ မငယ်ရပါ။

.en — 12px minimum, never smaller
3

Icon တစ်ခုတည်း ဘယ်တော့မှ မထား

ခလုတ်တိုင်းမှာ icon နဲ့ စာလုံး တွဲပါတယ်။ Icon က အဓိပ္ပာယ်ကို သယ်ဆောင်တာ မဟုတ်ဘဲ အလျင်မြန် ရှာတွေ့စေဖို့ပါ။

aria-hidden="true" on every icon
4

နံပါတ်ပြားက အမှတ်အသား

ရန်ကုန်ခရီးသည်က ဘတ်စ်ကားကို လမ်းတစ်ဖက်ကနေ နံပါတ်နဲ့ အရောင်နဲ့ မှတ်မိပါတယ်။ Interface ကလည်း အတူတူပဲ လုပ်ပါတယ်။

.plate — sm / default / lg
5

ဘောင်က နက်ပြာ၊ အလယ်က စာရွက်

Sidebar နဲ့ auth စာမျက်နှာက နက်ပြာ။ Content က အလင်း။ နံပါတ်ပြားတွေက အနက်ပေါ်မှာမှ ထင်းပါတယ်။

--navy-800 chrome / --paper content
6

မရနိုင်တာကို မှိန်မပြ — စကားနဲ့ ပြော

opacity က စာသား၊ နောက်ခံ၊ ဘောင် အားလုံးကို တစ်ပြိုင်နက် မှိန်စေလို့ အရေးအကြီးဆုံး အချက်အလက် — အကြောင်းရင်း — ပါ မှိန်သွားပါတယ်။ ဘေးဘောင်နဲ့ စာသားနဲ့ ပြောပါတယ်။

.is-blocked — no opacity anywhere in the system
